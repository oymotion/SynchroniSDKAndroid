# Cerelax 数据流用例（DATA-*）

> 能力以 `device_specs/cerelax_pro.py` 固化基线为准（硬断言）：支持流 7 个（EEG/PPG/SpO2/IMU/ACC/GYRO/Impedance），不支持流 7 个（EMG/GEST/Euler/Quat/MagAngle/ECG/BRTH）。
> 判定口径：`getDeviceInfo()` 的 `ChannelCount`（`>0` 支持，`==0` 不支持）；不以 `getParam('NTF_XXX')` 返回 `'ON'` 判定。

### DATA-FUNC-015 EEG 数据真实性：样本非全零、幅值合理（佩戴后）
- **优先级**：P1
- **测试目的**：验证 EEG 数据真实有效，而非"收到数据但全是零/恒定"的假流。
- **流程与逻辑**：佩戴头环起 `NTF_EEG`，统计一段时间内的 EEG 样本：单通道样本值非全零、方差非零、幅值在生理合理范围（具体单位 uV 与上限以设备规格为准），多通道间波形不恒等。
- **预期结果**：佩戴状态下 EEG 样本非全零、方差非零、幅值在合理区间；未佩戴/接触不良时数据为低幅值/无效，需人工区分并记录。
- **有效性说明**：覆盖"收到数据但内容为空"的失效模式；区分"设备不支持"与"未佩戴导致无有效数据"。
- **可自动化**：semi-auto
- **人工介入**：人工确认头环已正确佩戴、电极接触良好。
- **测试结果**：待测试
