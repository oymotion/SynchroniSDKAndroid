# Cerelax 参数用例（PARAM-*）

> Cerelax-Pro 采样率三套均支持 `getParam`/`setParam`（依据 `device_specs/cerelax_pro.py` 实测固化）：
>   - `EEG_SAMPLE_RATE`：`250|500|1000`，默认 `1000`
>   - `IMU_SAMPLE_RATE`：`50|100|200`，默认 `200`
>   - `PPG_SAMPLE_RATE`：`50|100|200|400`，默认 `50`
> 流开关 `NTF_*`、滤波 `FILTER_*` 按 spec 固化能力判定（硬断言，不以 `getParam('NTF_XXX')` 返回 `'ON'` 为准）。

- **预期结果**：返回 `OK`，`getParam` 状态一致。
- **有效性说明**：参数读写一致。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：待测试

### PARAM-FUNC-004 EEG_SAMPLE_RATE 设置（含逆向：750 非法）
- **优先级**：P0
- **测试目的**：验证 EEG 采样率设置（Cerelax 核心功能），含非法值逆向。
- **流程与逻辑**：从 `getParam("EEG_SAMPLE_RATE_LIST")` 获取可选值列表（预期 `1000|500|250`），逐一 `setParam("EEG_SAMPLE_RATE", value)` 后 `getParam("EEG_SAMPLE_RATE")` 核对；另测逆向值 `setParam("EEG_SAMPLE_RATE", "750")` 期待返回 `Error`（`750` 为非法值）。Cerelax 无 ECG，仅 EEG 单模态。
- **预期结果**：合法值 `1000/500/250` 设置返回 `OK`、`getParam` 一致；非法值 `750` 返回 `Error` 且不改变当前采样率。
- **有效性说明**：EEG 采样率是 Cerelax 核心参数（合法值 `1000|500|250`）；`750` 非法值逆向验证防止"越界值被误接受"。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：待测试
