# OB6000C 人工硬件用例（HW-MAN-*）

> 本文件为需要人工/仪器介入的硬件相关用例。
> HW-MAN-004（24h 老化）、HW-MAN-005（高低温）超出 SDK 软件测试范围，归硬件/可靠性团队，不在此展开。

### HW-MAN-001 BLE 链路 RSSI/连接稳定性人工验证
- **优先级**：P2
- **测试目的**：验证真实环境 BLE 链路稳定性。
- **流程与逻辑**：Android 端连接 OB6000C 并起 EEG 流；在不同距离/遮挡条件下记录 `BleDevice.rssi`、`setOnStateChangeListener` 状态变化、`setOnErrorListener` 与采样率波动。
- **预期结果**：有效范围内稳定（无频繁断连、采样率不明显掉速）；超出范围按预期断连并可恢复。
- **有效性说明**：真实射频环境验证；Android BLE 栈与手机天线差异会影响结果，需记录机型。
- **可自动化**：manual
- **人工介入**：移动设备、改变距离/遮挡，记录现象。
- **测试结果**：待测试

### HW-MAN-002 dongle 驱动绑定（仅 dongle 后端）
- **优先级**：P2
- **测试目的**：验证 dongle 引导（原 Python 用例）。
- **流程与逻辑**：**Android 不适用**：SDK 固定使用系统原生 BLE，无 USB dongle、无 `checkSetupDongle()`、无驱动安装/绑定流程。
- **预期结果**：不适用，记 SKIP。
- **有效性说明**：Android 无 dongle 链路，保留用例 ID 便于跨语言追溯。
- **可自动化**：manual
- **人工介入**：无
- **测试结果**：待测试

### HW-MAN-003 供电电压/上掉电时序与 SDK 重连
- **优先级**：P2
- **测试目的**：验证断电恢复。
- **流程与逻辑**：设备正常起流后人工断电再上电，观察 `setOnStateChangeListener`、`setOnErrorListener`、`setOnAutoReconnectListener` 与 `isAutoReconnecting()`，确认是否自动重连并恢复 EEG 流。
- **预期结果**：上电后 SDK 自动重连到 READY，并恢复 EEG 数据流（`autoReconnect=true` 时）。
- **有效性说明**：SDK 断电恢复响应；恢复时间与设备广播间隔/手机 BLE 栈有关，需记录实际耗时。
- **可自动化**：manual
- **人工介入**：断电/上电。
- **测试结果**：待测试
