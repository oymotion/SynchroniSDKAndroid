# gForceMax 人工硬件用例（HW-MAN-*）

> 本文件为需要人工/仪器介入的硬件相关用例。
> HW-MAN-004（24h 老化）、HW-MAN-005（高低温）超出 SDK 软件测试范围，归硬件/可靠性团队，不在此展开。
> **Android 口径**：宿主为 Android 手机/平板，BLE 为系统原生适配器（无 USB dongle、无后端切换）；
> 蓝牙开关与距离/遮挡操作均通过 Android 系统设置或物理移动完成。

### HW-MAN-001 BLE 链路 RSSI/连接稳定性人工验证
- **优先级**：P2
- **测试目的**：验证真实环境 BLE 链路稳定性。
- **流程与逻辑**：连接 gForceMax 后，在不同距离/遮挡（人体、桌面、墙体）下观察 `BleDevice.rssi` 变化、`deviceState` 与断连情况；断开后重新 `scan()` 验证可恢复。
- **预期结果**：有效范围内（约 10m 无遮挡）稳定出数；超出范围按预期断连并可恢复；RSSI 随距离单调下降趋势合理。
- **有效性说明**：真实射频环境验证；Android 宿主蓝牙芯片型号需记录到环境矩阵（不同厂商 BLE 栈行为有差异）。
- **可自动化**：manual
- **人工介入**：移动设备、改变距离/遮挡，记录现象。
- **测试结果**：待测试

### HW-MAN-003 供电电压/上掉电时序与 SDK 重连
- **优先级**：P2
- **测试目的**：验证断电恢复。
- **流程与逻辑**：连接起流后对 gForceMax 断电（拔电池/关机）再上电，观察 SDK 状态回调、`isAutoReconnecting()`、是否自动重连并恢复数据。
- **预期结果**：断电后观测到 `DISCONNECTED` 与错误回调；上电后 SDK 按 `setAutoReconnect(true)` 恢复连接到 Ready，并可恢复起流。
- **有效性说明**：SDK 断电恢复响应（对应 DEV-SM-008/012/016）；供电时序本身由硬件团队提供，本用例只验证 SDK 侧响应。
- **可自动化**：manual
- **人工介入**：断电/上电。
- **测试结果**：待测试

### HW-MAN-006 运行中关闭/打开宿主蓝牙，设备能否继续工作
- **优先级**：P2
- **测试目的**：验证 Android 系统蓝牙开关切换后，已连接的 gForceMax 能否继续工作（继续出数据 / 恢复连接）。
- **流程与逻辑**：
  1. 连接 gForceMax → init → 起流，确认数据正常到达。
  2. 关闭 Android 蓝牙，观察 `isEnable()`、`getDeviceState()`、`isDataTransfering()`、数据是否中断、是否触发错误/断开回调。
  3. 重新打开蓝牙，观察 SDK 是否自动恢复连接与数据，或需重新 `scan()`/`connect()`。
- **预期结果**：关闭蓝牙时 SDK 能感知（`isEnable()==false` 或收到断开/错误回调），已有连接按预期断连/报错而不崩溃；重新打开后能恢复，设备继续工作（重新出数据）。
- **有效性说明**：验证宿主蓝牙开关切换下 SDK 的恢复能力，与 CTRL-FUNC-001/002 相关联；Android 关闭蓝牙通常由系统直接断开 GATT，恢复一般需重新扫描连接，实际行为需记录。
- **可自动化**：semi-auto
- **人工介入**：运行中人工关闭/打开宿主蓝牙。
- **测试结果**：待测试

- **有效性说明**：标 `@Ignore("Android 无 dongle 热插拔，等价场景见 HW-MAN-006")`；不重复建设用例。
- **可自动化**：manual
- **人工介入**：无（不执行 dongle 拔插；如执行等价场景则人工切换飞行模式）。
- **测试结果**：待测试

## 系统级异常场景（SYS-ROB-*）

### SYS-ROB-001 打开蓝牙后 startScan 成功并进入扫描态
- **优先级**：P0
- **测试目的**：验证系统级异常/切换场景下 SDK 不崩溃，能按预期报错并恢复。
- **流程与逻辑**：关闭系统蓝牙 → 初始化 controller → 打开蓝牙 → `startScan(1000)` → 等待扫描回调。
- **预期结果**：打开蓝牙后 `startScan` 成功；`onScanStateChange(true)` 触发；能扫到目标设备；不崩溃。
- **有效性说明**：依赖系统设置或人工操作，无法纯自动化稳定复现。
- **可自动化**：semi-auto
- **人工介入**：人工在系统设置/快捷开关中关闭再打开蓝牙。
- **测试结果**：已登记（Demo 自动化，人工执行）
